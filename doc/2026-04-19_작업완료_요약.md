### TypeScript 제네릭 구조 도입

#### Before (기존)
```javascript
// 보험 타입이 하드코딩됨
if (text.includes('보험상품')) {
  keyword = '보험모집인';
} else if (text.includes('일반보험상품')) {
  keyword = '설계사';
} else if (text.includes('자동차보험상품')) {
  keyword = '설계사';
}
```

#### After (개선)
```javascript
// 타입 정의
/**
 * @typedef {'장기'|'일반'|'자동차'} InsuranceType
 */

// 설정 중앙화
const INSURANCE_CONFIGS = {
  장기: { type: '장기', keyword: '보험모집인', detectPattern: '보험상품' },
  일반: { type: '일반', keyword: '설계사', detectPattern: '일반보험상품' },
  자동차: { type: '자동차', keyword: '설계사', detectPattern: '자동차보험상품' }
};

// 제네릭 함수
const detectedType = detectInsuranceType(text);
const keyword = getInsuranceKeyword(detectedType);
```

### 해결한 3가지 주요 오류

1. **PDF 드래그앤드롭 미리보기 미작동**
   - 원인: 드래그앤드롭 파일이 input.files에 제대로 설정 안 됨
   - 해결: 드래그앤드롭 파일을 별도 변수에 저장하고 우선순위 설정

2. **ArrayBuffer Detach 오류**
   - 원인: pdf.js가 ArrayBuffer를 소비한 후 PDFDocument.load에서 재사용 시도
   - 해결: 앵커 찾기용 복사본 생성, 원본 보존

3. **Canvas 미리보기 표시 안 됨**
   - 원인: HTML 인라인 style과 CSS 우선순위 충돌
   - 해결: 인라인 스타일 제거, CSS 클래스로 표시 관리

### PDF 미리보기 기능 추가

```javascript
async function showPdfPreview(pdfBytes) {
  const doc = await pdfjsLib.getDocument({ data: pdfBytes }).promise;
  const page = await doc.getPage(1);
  
  const viewport = page.getViewport({ scale: 1.5 });
  const canvas = el.pdfPreviewCanvas;
  const context = canvas.getContext('2d');
  
  canvas.width = viewport.width;
  canvas.height = viewport.height;
  
  await page.render({ canvasContext: context, viewport }).promise;
  canvas.classList.add('visible');
}
```

## 🔴 발생한 오류 및 해결 과정

### 오류 1: PDF 파일 업로드 후 미리보기 미작동

#### 증상
```
실패: PDF 파일 업로드 또는 URL 입력이 필요합니다.
```
- 드래그앤드롭으로 PDF 파일을 선택해도 미리보기가 표시되지 않음
- 콘솔에 파일 선택 로그는 출력되나 후속 처리 실패

#### 근본 원인 분석

**문제 1: 드래그앤드롭 파일 저장 미흡**
- 드래그앤드롭으로 선택한 파일이 `input.files`에 제대로 설정되지 않음
- `getInputBytes()` 함수에서 파일을 찾지 못함

**문제 2: 전역 변수 스코프 문제**
- `insurance-types.js` 모듈에서 `pdfjsLib`에 접근 불가
- 전역 변수 의존성으로 인한 모듈 분리 실패

**문제 3: ArrayBuffer Detach**
- `findAgentAnchor()`에서 pdf.js가 ArrayBuffer를 소비
- 이후 `PDFDocument.load()`에서 같은 바이트 사용 시 detach 오류

#### 해결 방법

**Step 1: 드래그앤드롭 파일 별도 저장**
```javascript
let draggedPdfFile = null;
let draggedSignFile = null;

function handleFileSelect(file, type) {
  if (type === 'pdf') {
    draggedPdfFile = file;  // ← 파일을 별도 변수에 저장
  } else {
    draggedSignFile = file;
  }
  // ...
}
```

**Step 2: getInputBytes에서 우선순위 설정**
```javascript
async function getInputBytes(fileInput, urlInput, label) {
  // 1순위: 드래그앤드롭 파일
  if (label === 'PDF' && draggedPdfFile) {
    const bytes = new Uint8Array(await draggedPdfFile.arrayBuffer());
    validateInputBytes(bytes, label);
    return { bytes, fileName: draggedPdfFile.name };
  }
  
  // 2순위: input.files
  if (fileInput.files?.[0]) { ... }
  
  // 3순위: URL
  if (urlInput.value.trim()) { ... }
}
```

**Step 3: insurance-types.js에서 pdfjsLib 파라미터 전달**
```javascript
// Before: 전역 변수 직접 접근 (모듈에서 불가)
const doc = await pdfjsLib.getDocument({ data: pdfBytes }).promise;

// After: 파라미터로 전달
async function findAgentAnchor(pdfBytes, pdfjsLibInstance) {
  const doc = await pdfjsLibInstance.getDocument({ data: pdfBytes }).promise;
}

// app.js에서 호출
const anchor = await findAgentAnchor(pdfBytesForAnchor, pdfjsLib);
```

**Step 4: ArrayBuffer Detach 방지**
```javascript
// pdf.js가 ArrayBuffer를 소비하므로 복사본 전달
const pdfBytesForAnchor = new Uint8Array(pdfBytes);
const anchor = await findAgentAnchor(pdfBytesForAnchor, pdfjsLib);

// 원본은 PDFDocument.load에서 사용
const pdfDoc = await PDFDocument.load(pdfBytes);
```

### 오류 2: PDF 미리보기 기능 미작동

#### 증상
```
PDF 파일 드래그앤드롭 후에도 Canvas 미리보기가 표시되지 않음
```

#### 근본 원인 분석

**원인 1: HTML 인라인 스타일과 CSS 우선순위 충돌**
```html
<!-- HTML의 인라인 style이 CSS보다 우선순위 높음 -->
<canvas id="pdfPreviewCanvas" style="display: none; ..."></canvas>
```

```javascript
// JavaScript의 style.display도 CSS보다 우선순위 높지만
// 초기값이 display: none으로 설정되어 있어 덮어쓰기 실패
canvas.style.display = 'block';
```

**원인 2: CSS 선택자 우선순위**
```css
.preview-box {
  display: flex;  /* 인라인 style에 의해 무시됨 */
}
```

#### 해결 방법

**Step 1: HTML에서 인라인 스타일 제거**
```html
<!-- Before -->
<canvas id="pdfPreviewCanvas" style="display: none; ..."></canvas>

<!-- After -->
<canvas id="pdfPreviewCanvas" class="pdf-canvas"></canvas>
```

**Step 2: CSS에서 클래스로 관리**
```css
.preview-box canvas {
  display: none;  /* 기본: 숨김 */
  max-width: 100%;
  max-height: 150px;
}

.preview-box canvas.visible {
  display: block;  /* visible 클래스 추가 시 표시 */
}
```

**Step 3: JavaScript에서 클래스 추가**
```javascript
// Before: style 직접 조작
canvas.style.display = 'block';

// After: 클래스 추가
canvas.classList.add('visible');
```

### 오류 3: "Failed to parse PDF document - No PDF header found"

#### 증상
```
실패: Failed to parse PDF document (line:0 col:0 offset=0): No PDF header found
```

#### 근본 원인 분석

**원인 1: PDF 헤더 검증 부족**
- 정규화된 PDF 바이트가 실제로 유효한지 확인 미흡
- pdf.js의 PDFParser가 헤더를 찾지 못함

**원인 2: ArrayBuffer 손상**
- 이전 단계에서 ArrayBuffer가 detach되어 손상된 데이터 전달

#### 해결 방법

**Step 1: normalizePdfBytes 함수 강화**
```javascript
function normalizePdfBytes(bytes) {
  console.log(`[normalizePdfBytes] 입력 바이트 크기: ${bytes.length}`);
  
  const offset = findPdfHeaderOffset(bytes);
  console.log(`[normalizePdfBytes] PDF 헤더 오프셋: ${offset}`);
  
  if (offset < 0) {
    // 16진수로 첫 100바이트 확인
    const hexString = Array.from(bytes.slice(0, 100))
      .map(b => b.toString(16).padStart(2, '0'))
      .join(' ');
    console.error(`[normalizePdfBytes] 첫 100바이트(16진수): ${hexString}`);
    throw new Error('올바른 PDF 헤더를 찾지 못했습니다');
  }
  
  // ...
}
```

**Step 2: ArrayBuffer 복사본 생성**
```javascript
// ArrayBuffer를 detach하지 않기 위해 복사본 사용
const pdfBytesForAnchor = new Uint8Array(pdfBytes);
await findAgentAnchor(pdfBytesForAnchor, pdfjsLib);

// 원본 pdfBytes는 intact 상태 유지
const pdfDoc = await PDFDocument.load(pdfBytes);
```

## 🔧 구현 상세 기록

### PDF 미리보기 함수 구현

```javascript
/**
 * PDF 미리보기 표시 함수
 * @param {Uint8Array} pdfBytes - PDF 바이트 데이터
 */
async function showPdfPreview(pdfBytes) {
  try {
    console.log('[showPdfPreview] 입력 바이트 크기:', pdfBytes.length);
    
    const canvas = el.pdfPreviewCanvas;
    if (!canvas) {
      console.error('[showPdfPreview] Canvas 요소를 찾을 수 없음');
      return;
    }

    // pdf.js 문서 로드
    const pdfDoc = await pdfjsLib.getDocument({ data: pdfBytes }).promise;
    const page = await pdfDoc.getPage(1);
    
    // Viewport 설정 (1.5배 스케일)
    const viewport = page.getViewport({ scale: 1.5 });
    
    // Canvas 크기 조정
    const context = canvas.getContext('2d');
    canvas.width = viewport.width;
    canvas.height = viewport.height;
    
    // 렌더링
    const renderTask = page.render({ 
      canvasContext: context, 
      viewport: viewport 
    });
    await renderTask.promise;
    
    // 표시
    canvas.classList.add('visible');
    console.log('[showPdfPreview] PDF 미리보기 생성 완료');
  } catch (error) {
    console.error('[showPdfPreview] 오류:', error);
  }
}
```

### 파일 선택 처리 개선

```javascript
function handleFileSelect(file, type) {
  if (!file) return;

  console.log(`[파일 선택] ${type}: ${file.name} (${file.size} bytes)`);

  // 드래그앤드롭 파일 저장
  if (type === 'pdf') {
    draggedPdfFile = file;
  } else {
    draggedSignFile = file;
  }

  // input.files 업데이트
  const input = type === 'pdf' ? el.pdfFile : el.signFile;
  const dataTransfer = new DataTransfer();
  dataTransfer.items.add(file);
  input.files = dataTransfer.files;

  // UI 업데이트
  const container = type === 'pdf' ? el.dropZonePdf : el.dropZoneSign;
  container.classList.add('has-file');
  const filenameEl = container.querySelector('.filename');
  if (filenameEl) filenameEl.textContent = file.name;

  // 미리보기 표시
  if (type === 'sign' && file.type.startsWith('image/')) {
    const reader = new FileReader();
    reader.onload = (e) => {
      el.signPreview.src = e.target?.result;
      el.signPreview.style.display = 'block';
    };
    reader.readAsDataURL(file);
  } else if (type === 'pdf') {
    const reader = new FileReader();
    reader.onload = async (e) => {
      const pdfBytes = new Uint8Array(e.target?.result);
      await showPdfPreview(pdfBytes);
    };
    reader.readAsArrayBuffer(file);
  }

  setStatus(`${type === 'pdf' ? 'PDF' : '서명 이미지'} 파일이 선택되었습니다: ${file.name}`, 'success');
  setTimeout(() => setStatus(''), 2000);
}
```

async function signPdf() {

## 🎓 배운 점

1. **JavaScript 파일 I/O**
   - FileReader API의 readAsArrayBuffer vs readAsDataURL
   - DataTransfer를 통한 input.files 업데이트

2. **PDF 처리**
   - pdf.js와 pdf-lib의 상보적 사용
   - ArrayBuffer의 수명 주기 관리

3. **CSS와 JavaScript 우선순위**
   - 인라인 스타일의 높은 우선순위
   - 클래스 기반 스타일 관리의 이점

4. **모듈화와 전역 변수**
   - 모듈에서 전역 변수에 접근 불가
   - 파라미터 전달을 통한 의존성 주입
